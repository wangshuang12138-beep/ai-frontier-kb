### 1.3 差异分析

**① 输出/输入倍率是隐性定价杠杆。** 海外三家统一 5×，这不是巧合——Agent 时代输出才是消耗大头（一次工具调用链路里输出 token 远多于输入），5× 的倍率实际上是对 Agent 工作负载的定向加价。国内普遍 3–4×，等于在 Agent 场景里偷偷比海外便宜 20–40%。**看报价单只盯输入价是销售视角，看输出价才是架构师视角。**

**② 缓存定价暴露真实边际成本。** 缓存命中价占输入价的比例：DeepSeek ≈2–3%、Claude 5–10%、Kimi 10%、GLM 25%。比例越低，说明厂商越敢按边际成本定价，也意味着它的推理集群利用率压力越小。缓存价是观察一家厂商算力供需的**公开情报窗口**。

**③ 定价创新的三种思路对应三种经营逻辑：**
- DeepSeek 峰谷分时 = 电力/IDC 思维：把算力当潮汐资源卖，引导负载错峰，是infra 公司的做法
- 豆包按输入长度区间 = 产品设计思维：把"长上下文更贵"做成显性格栅，引导开发者做短上下文架构，本质是替自己降峰值负载
- 腾讯/七牛 Token Plan = 电信思维：月租批发价锁定高频客户，用确定性换现金流，和卖带宽套餐同构

**④ 免费档是生态武器不是慈善。** GLM-4.7-Flash 全免费、ERNIE Lite/Speed 免费、Gemini 免费档砍到 Flash-Lite——免费模型的共同点是：足够好到让你不写代码就离不开，但不够好到能撑生产负载。它们买走的是开发者的"第一次调用"和默认选项。

**⑤ 同一模型内外价差存在但收敛中。** Kimi K3 国内 ¥20/¥100 vs K3.1 Pro 国际 $2/$10（≈¥14/¥71），新一代直接全球同价；MiniMax 海外 $0.30/$1.20 ≈ 国内五折价。趋势是**国内价成为地板价、国际价锚定 OpenAI 的 6–7 折**。

## 二、智能体产品对比

### 2.1 通用 Agent 订阅对比

| 产品 | 入门付费档 | 主力档 | 顶档 | 额度表述 |
|---|---|---|---|---|
| ChatGPT | $19.99 Plus | 同左 | $200 Pro（$500 传闻） | "约 10× Plus"（黑盒倍数） |
| Claude | $20 Pro | $100 Max 5× | $200 Max 20× | 倍数制（黑盒） |
| Gemini | $4.99 AI Plus | $19.99 AI Pro | $99.99/199.99 Ultra 5×/20× | 倍数制（黑盒） |
| Grok | $8 Plus | $30 Premium | $200 Ultra | "4× more usage"（黑盒） |
| Manus | $20 Standard | $40 Custom | $200 Extended | **积分制（白盒）** |
| 扣子空间 | 免费 | — | — | 免费策略 |

### 2.2 企业级平台对比

| 平台 | 计费锚 | 价格 | 适合 |
|---|---|---|---|
| Salesforce Agentforce | 成功对话 | $2/次（约 $25k/年起） | 有明确客服 ROI 的企业 |
| Copilot Studio | 消息条数 | $200/月含 25k 条，$0.01/条超额 | 已买 M365 的组织 |
| 扣子专业版 | 资源点 | 智能体 2 点/次 ≈ ¥0.002/次 | 国内 C 端/轻量场景 |
| Dify | 席位 | $59–159/月 + 自模型费 | 技术团队自建 |

### 2.3 差异分析

**① 订阅额度的"黑盒 vs 白盒"是两种信任策略。** ChatGPT/Claude/Gemini 用"×5、×20"的倍数制——好处是涨价时不用改价目表（悄悄调额度即可），坏处是用户永远在猜还剩多少。Manus 的积分制把每次任务成本显性化：复杂任务 500–900 积分，用户自己会做任务分解。**倍数制服务的是厂商的定价自由，积分制服务的是用户的成本预期。** 企业采购时，白盒计价更容易过财务关，黑盒计价更容易在内部推广（反正算不清）。

**② 按结果付费（$2/对话）和按量付费的本质差别：谁承担任务失败的风险。** Agentforce 只对"成功对话"收费，等于把 Agent 可靠性的风险卖给厂商——这就是为什么它敢按"对话"而不是"token"计价：只有当模型足够稳，按结果收费才不至于亏损。**定价单位的颗粒度 = 厂商对自家模型可靠性的置信度。** 反过来，所有按 token 计费的 Agent 平台，都在用基础设施的计价方式掩盖"我还不能保证每次任务都成"的事实。

**③ 扣子的资源点是补贴定价。** 智能体调用 2 点/次 ≈ ¥0.002，而一次 Agent 任务背后是多次模型推理+插件+检索，真实成本远高于此。字节在用手游式逻辑买生态规模：先让百万级 Agent 在平台上跑起来，再谈变现。对比 Manus 单任务最低 200 积分（≈$1/次任务），扣子便宜三个数量级——这不是成本差异，是**商业模式差异**：Manus 卖"任务结果"，扣子卖"生态入口"。

**④ $20/月是 Agent 时代的价格锚，但这个锚正在松动。** ChatGPT Plus（2022）、Claude Pro、Manus Standard、Gemini AI Pro 都锚在 $20 上下，沿用 SaaS 的"一杯咖啡"定价心理学。但顶档正在快速分化：$100–200 成为重度用户新常态，$500 传闻档（Pro Max）说明头部 1% 用户的支付意愿远超旧价目表。**订阅经济的规律在 AI 上重演：底部免费化、腰部 $20 固化、顶部无上限化。**

**⑤ 国内外平台差一个收费世代。** 国外平台（Agentforce/Copilot Studio）已经在收"结果税"和"席位税"，国内平台（元器免费、扣子近乎免费、百炼只收模型费）还在"平台免费、模型收费"的阶段——即**平台层不收费，靠底层模型走量赚钱**。这和一个老规律一致：中国 toB 软件难收平台费，中国 AI 平台也难收 Agent 编排费；差异在于，这次平台层可能永远不收费，因为字节阿里腾讯的平台费，本质是模型市场份额的收购成本。

## 三、交叉洞察：token 降价如何重估本地算力

对正在评估本地部署（边缘盒子 / 私有化）的团队，上面的数字给出一条临界线：

- 旗舰 API 输入价 $2–4 / 输出 $10–20 每百万 token，且逐年 5–10 倍速下降；MiniMax M3 已把 1M 上下文做到 ¥3.15/¥12.60
- 意味着**"纯成本驱动"的本地部署论证在快速失效**——按当前降价斜率，两年内云端旗舰推理成本将低于自购 GPU 的摊销成本
- 本地算力的剩余护城河只剩下三个**非价格变量**：数据不出域（合规）、时延（确定性）、断网可用（可靠性）

结论不是"不要本地部署"，而是：本地部署的采购话术必须从"省 API 钱"转向"买确定性"。这跟卖保险而不是卖理财是同一种话术迁移。
