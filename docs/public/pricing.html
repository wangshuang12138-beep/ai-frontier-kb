三分钟速览

只想知道结论？看这 6 条。所有原始数据都还在下方，点开折叠块即可逐档核对。

1

旗舰输出价：国外 $20，国内 ¥28–36

GPT-5.6 Sol 与 Claude Opus 5.5 并列 $20/百万输出；国内旗舰 GLM-5.3 ¥28、qwen3.8-max ¥36。国内输出/输入倍率 3–4×（海外整齐 5×），Agent 场景国内实际便宜 20–40%。

2

计费单位正在从 token 迁向"任务/结果"

Manus 按积分扣任务、Agentforce $2/次成功对话、腾讯 WorkBuddy 直接卖 Token 月包。token 度量的是计算量，"一件事"才是用户心智——谁按任务收费，谁就把不可预期的风险揽回自己身上。

3

缓存命中价 = 厂商边际成本情报

命中价占输入价比例：DeepSeek ≈2–3%、Claude 5–10%、Kimi 10%、GLM 25%。比例越低，说明其算力越宽裕、越敢按边际成本定价。

4

免费档是生态武器，不是慈善

GLM-4.7-Flash 全免费、ERNIE Lite 免费、Gemini 免费档砍到 Flash-Lite——共同点是好用到离不开、又不够好用撑生产。买的不是用户，是"第一次调用"。

5

$20/月价格锚在松动

底部免费、腰部 $20 固化（Plus / Pro / Standard 同锚）、顶部分化到 $100–200（$500 传闻未官宣）。头部 1% 用户的支付意愿远超旧价目表。

6

token 年降 5–10 倍，本地算力改卖"确定性"

云端旗舰推理成本两年内将低于自购 GPU 摊销。"省 API 钱"的论证正在失效，剩余护城河只有数据不出域、时延、断网可用——卖保险，不是卖理财。

03

对比与差异分析

十一条判断，每条对应一个可执行的选型或谈判动作。

大模型 API · 五条

M-01

输出/输入 5× 倍率是 Agent 时代的定向加价

海外三家整齐划一不是巧合——Agent 链路输出 token 远多于输入。国内普遍 3–4×，在 Agent 场景实际比海外便宜 20–40%。只盯输入价是销售视角，看输出价才是架构师视角。

M-02

缓存定价 = 算力供需的公开情报窗口

缓存命中价占输入价比例：DeepSeek ≈2–3%、Claude 5–10%、Kimi 10%、GLM 25%。比例越低越敢按边际成本定价，推理集群利用率压力越小。缓存的命中条件是"新请求与历史请求存在逐字节一致的前缀且未过期"。

M-03

三种定价创新对应三种经营逻辑

DeepSeek 峰谷分时 = 电力/IDC 思维；豆包按输入长度区间 = 产品设计思维（替自己降峰值）；腾讯 Token Plan = 电信思维（确定性换现金流）。

M-04

免费档是生态武器，不是慈善

GLM-4.7-Flash 全免费、ERNIE Lite 免费、Gemini 免费档砍到 Flash-Lite——共同点是足够好到离不开、不够好到撑生产。它们买走的是开发者的"第一次调用"。

M-05

内外价差在收敛：国内价成为地板价

Kimi 新一代全球同价；MiniMax 海外价 ≈ 国内五折价。趋势清晰：国际价锚定 OpenAI 的 6–7 折，国内价是地板。

智能体产品 · 六条

A-01

额度黑盒 vs 白盒，是两种信任策略

ChatGPT/Claude/Gemini 的"×5 ×20"倍数制服务厂商的定价自由；Manus 积分制服务用户的成本预期。企业采购时白盒好过财务关，黑盒好做内部推广。

A-02

定价颗粒度 = 对模型可靠性的置信度

Agentforce 敢按"成功对话"收费，是把 Agent 可靠性风险卖回给厂商。还在按 token 计费的 Agent 平台，实质在说"我不能保证每次都成"。

A-03

扣子资源点是补贴定价，差三个数量级

智能体调用 ≈¥0.002/次 vs Manus ≈$1/次任务。不是成本差异，是商业模式差异：Manus 卖"任务结果"，扣子卖"生态入口"。

A-04

$20/月价格锚在松动：底部免费、腰部固化、顶部无上限

ChatGPT Plus / Claude Pro / Manus Standard 同锚 $20。但顶档快速分化至 $100–200，$500 传闻档说明头部 1% 用户支付意愿远超旧价目表。

A-05

国内平台差一个收费世代

国外在收"结果税 / 席位税"，国内还在"平台免费、模型收费"阶段——平台费本质是字节阿里腾讯的模型市场份额收购成本，且可能永远不收。

A-06

Token 计费与用户心智错位，催生"可控性"卖点

计费单位是计算量，用户心智单位是"一件事"。三层不可预期：输出长度不归用户管、Agent 循环放大（同一问题可差 100 倍）、多轮对话 O(n²) 重复计费。拧紧顺序：控制台设硬预算 → max_tokens 封顶 → Agent 限循环数 → 长会话开新窗/做摘要。按任务/按结果计费（Manus 积分、Agentforce 按对话）本质是计费单位向用户心智回迁。

交叉洞察：token 降价如何重估本地算力

旗舰 API 输入 $2–4 / 输出 $10–20 每百万 tokens 且逐年 5–10 倍速降；MiniMax M3 已把 1M 上下文做到 ¥3.15/¥12.60。按此斜率，两年内云端旗舰推理成本将低于自购 GPU 摊销成本——"纯成本驱动"的本地部署论证正在失效。

本地算力剩余护城河只剩三个非价格变量：数据不出域（合规）、时延（确定性）、断网可用（可靠性）。结论不是"不要本地部署"，而是采购话术必须从"省 API 钱"转向"买确定性"——卖保险，而不是卖理财。token 计费的失控感（A-06）恰好是最具体的印证：云是表在跑，本地盒子是表停了，成本从变量变成买时就知道的固定数。
