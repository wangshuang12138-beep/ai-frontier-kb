03

对比与差异分析

十条判断，每条对应一个可执行的选型或谈判动作。展开论证见明细文档第三章。

大模型 API · 五条

M-01

输出/输入 5× 倍率是 Agent 时代的定向加价

海外三家整齐划一不是巧合——Agent 链路输出 token 远多于输入。国内普遍 3–4×，在 Agent 场景实际比海外便宜 20–40%。只盯输入价是销售视角，看输出价才是架构师视角。

M-02

缓存定价 = 算力供需的公开情报窗口

缓存命中价占输入价比例：DeepSeek ≈2–3%、Claude 5–10%、Kimi 10%、GLM 25%。比例越低越敢按边际成本定价，推理集群利用率压力越小。

M-03

三种定价创新对应三种经营逻辑

DeepSeek 峰谷分时 = 电力/IDC 思维；豆包按输入长度区间 = 产品设计思维（替自己降峰值）；腾讯 Token Plan = 电信思维（确定性换现金流）。

M-04

免费档是生态武器，不是慈善

GLM-4.7-Flash 全免费、ERNIE Lite 免费、Gemini 免费档砍到 Flash-Lite——共同点是足够好到离不开、不够好到撑生产。它们买走的是开发者的"第一次调用"。

M-05

内外价差在收敛：国内价成为地板价

Kimi 新一代全球同价；MiniMax 海外价 ≈ 国内五折价。趋势清晰：国际价锚定 OpenAI 的 6–7 折，国内价是地板。

智能体产品 · 五条

A-01

额度黑盒 vs 白盒，是两种信任策略

ChatGPT/Claude/Gemini 的"×5 ×20"倍数制服务厂商的定价自由；Manus 积分制服务用户的成本预期。企业采购时白盒好过财务关，黑盒好做内部推广。

A-02

定价颗粒度 = 对模型可靠性的置信度

Agentforce 敢按"成功对话"收费，是把 Agent 可靠性风险卖回给厂商。还在按 token 计费的 Agent 平台，实质在说"我不能保证每次都成"。

A-03

扣子资源点是补贴定价，差三个数量级

智能体调用 ≈¥0.002/次 vs Manus ≈$1/次任务。不是成本差异，是商业模式差异：Manus 卖"任务结果"，扣子卖"生态入口"。

A-04

$20/月价格锚在松动：底部免费、腰部固化、顶部无上限

ChatGPT Plus / Claude Pro / Manus Standard 同锚 $20。但顶档快速分化至 $100–200，$500 传闻档说明头部 1% 用户支付意愿远超旧价目表。

A-05

国内平台差一个收费世代

国外在收"结果税 / 席位税"，国内还在"平台免费、模型收费"阶段——平台费本质是字节阿里腾讯的模型市场份额收购成本，且可能永远不收。

交叉洞察：token 降价如何重估本地算力

旗舰 API 输入 $2–4 / 输出 $10–20 每百万 tokens 且逐年 5–10 倍速降；MiniMax M3 已把 1M 上下文做到 ¥3.15/¥12.60。按此斜率，两年内云端旗舰推理成本将低于自购 GPU 摊销成本——"纯成本驱动"的本地部署论证正在失效。

本地算力剩余护城河只剩三个非价格变量：数据不出域（合规）、时延（确定性）、断网可用（可靠性）。结论不是"不要本地部署"，而是采购话术必须从"省 API 钱"转向"买确定性"——卖保险，而不是卖理财。
